# gamemaker-test-project (UFO Hijack)
This is a scrapped project I tried making almost a decade ago that I revived after finally obtaining a free copy of gamemaker studio (the software is no longer paid) It's a basic tech demo to prove to myself that I can make basic game maker studio games.

Assets used for this project are...uh...I don't remember where I got them, they've been sitting in an obscure folder on my pc for almost a decade.

The project was exported into a exe file so all you need to do is download the project and run the exe (note: DO NOT MOVE THE FILES OUT OF THE FOLDER, it requires the other files in the same directory to function. Data.win is the file that contains the assets for the game.)
